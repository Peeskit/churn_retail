============================================================
  CHURN INTELLIGENCE DASHBOARD — HOW TO RUN
============================================================

REQUIREMENTS
------------
- Python 3.8+
- Node.js 18+


------------------------------------------------------------
STEP 1 — Install Python dependencies (first time only)
------------------------------------------------------------

    pip install -r requirements.txt
    pip install fastapi "uvicorn[standard]" pandas numpy


------------------------------------------------------------
STEP 2 — Run the ML pipeline
------------------------------------------------------------

Run this from the project root folder:

    python main.py

This trains the models and generates all dashboard data files
under outputs/results/ and outputs/models/.

To skip LSTM (faster, no TensorFlow needed):

    python main.py --skip-lstm


------------------------------------------------------------
STEP 3 — Start the API server
------------------------------------------------------------

Run this from the project root folder (in Terminal 1):

    python3 -m uvicorn api.main:app --reload --port 8000

API will be available at: http://localhost:8000
API docs at:              http://localhost:8000/docs


------------------------------------------------------------
STEP 4 — Start the UI
------------------------------------------------------------

Run this in a second terminal from the ui/ folder:

    cd ui
    npm install        (first time only)
    npm run dev

Dashboard will open at: http://localhost:5173


------------------------------------------------------------
DASHBOARD PAGES
------------------------------------------------------------

  Model Performance   — metrics table, bar chart, feature importance
  Outcomes            — KPI cards, churn distribution, customer table
  What-If Tools       — threshold slider, retention simulator, PR curve
  Executive Dashboard — revenue trend, country chart, strategic actions


------------------------------------------------------------
FOLDER STRUCTURE
------------------------------------------------------------

  main.py             — ML pipeline entry point
  config.py           — all hyperparameters and paths
  src/                — pipeline modules (loader, cleaner, trainer, etc.)
  api/main.py         — FastAPI backend
  ui/                 — React frontend (Vite + Tailwind + Recharts)
  data/               — raw Excel dataset (not tracked in git)
  outputs/            — models, plots, results (not tracked in git)


------------------------------------------------------------
NOTES
------------------------------------------------------------

- Run Step 2 before Step 3 — the API reads files generated by the pipeline.
- Both Step 3 and Step 4 must be running at the same time to use the dashboard.
- If port 8000 is busy:  lsof -ti :8000 | xargs kill -9
- If port 5173 is busy:  lsof -ti :5173 | xargs kill -9
